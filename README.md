# 跨境电商行业研究 AI Agent

一个基于大语言模型 Function Calling 机制的行业研究助手，整合宏观数据、公司财务、股价对比、相关性回归分析，自动生成可用于行业研究报告的分析结论。

## 项目背景

以 Temu（母公司拼多多）、AliExpress（母公司阿里巴巴）为代表的跨境电商赛道为研究对象，对比亚马逊、京东等同业公司，构建"宏观市场潜力 → 行业竞争格局 → 重点公司体检 → 同业联动性"的完整分析框架。

## 功能特性

- 🌍 **宏观趋势分析**：拉取世界银行公开数据，追踪目标市场（美国/英国/德国/巴西）互联网普及率趋势
- 📊 **多公司横向对比**：归一化处理后对比拼多多、阿里巴巴、亚马逊、京东近3年股价表现
- 🔍 **单公司财务深挖**：市值、市盈率、营收增长率、毛利率等真实财务指标
- 📈 **相关性与回归分析**：量化两家公司股价的联动强度，识别并规避"伪相关"陷阱
- 🛠️ **AI 自主工具调用**：模型根据自然语言问题自主判断调用哪个分析工具
- 🧹 **输出清洗机制**：过滤免费模型可能泄漏的思考过程标记，保证输出整洁
- 🎯 **统计规范约束**：通过 System Prompt 规避常见的统计概念误用（如混淆相关系数与概率）

## 技术栈

Python · pandas · yfinance · wbgapi（世界银行数据）· scipy（统计与回归）· matplotlib · OpenRouter API（Function Calling）

## 核心工具（Function Calling）

| 工具名 | 功能 | 用到的分析方法 |
|---|---|---|
| `get_macro_trend` | 目标市场互联网普及率趋势 | 世界银行公开数据、缺失值处理 |
| `compare_companies` | 多公司股价横向对比 | 归一化处理，避免绝对值误导 |
| `company_deep_dive` | 单公司财务指标查询 | 真实财务快照数据 |
| `analyze_correlation` | 两公司股价联动性分析 | 收益率转换、相关系数、线性回归、R²、P值 |

## 使用示例
用户：跨境电商目标市场的互联网普及率趋势怎么样？
Agent：[调用 get_macro_trend] → 美国94.7% / 英国95.5% / 德国93.5% / 巴西84.5%
成熟市场渗透率接近饱和，巴西等新兴市场增长空间更大

用户：拼多多和阿里巴巴的股价联动关系强不强？
Agent：[调用 analyze_correlation] → 相关系数0.51，R²=0.26
中等正相关但联动性有限，各自74%的波动由独立因素驱动

## 开发过程中发现并解决的真实问题

1. **伪相关陷阱**：直接用股价数值计算相关性会被长期趋势污染（曾得出-0.117的误导性负相关），改用日收益率（涨跌幅）计算后得出0.604的合理正相关，验证了"分析股价关系必须用收益率而非价格水平"这一金融数据分析基本原则

2. **数据代理指标的局限性**：最初用"互联网普及率"代表"线上购物渗透率"，经审视后明确这只是受限于免费数据可得性的代理指标，非精确等价，并在方法论上作出说明

3. **免费模型工具调用不稳定性**：不同请求可能路由到不同的免费模型，工具调用成功率存在波动，通过明确的工具描述（description）与参数设计提升调用准确率

4. **模型思考过程泄漏**：部分免费模型会在最终输出中泄漏内部推理标记（如`<channel|>`），通过封装独立的`clean_ai_output()`清洗函数解决，并保留可扩展性以应对不同模型的泄漏格式

5. **统计概念误用**：模型曾将"相关系数0.51"错误解读为"51%概率同向变动"，混淆了相关系数与R²的含义，通过在System Prompt中明确统计规范予以修正
